## 4) Public Contracts (frozen in v0.2)

### 4.1 Sorcerer façade

```py
class Sorcerer:
    def __init__(self, *, default: str | None = None): ...

    def add_connection(self, name: str, dsn: str | None, driver: str, dialect: Dialect,
                       connect_kwargs: dict[str, Any] | None = None) -> None: ...

    def use(self, name: str) -> None:  # swap current connection by name
        ...

    @property
    def client(self) -> "SorcererClient": ...  # active client for current connection
```

### 4.2 SorcererClient (sync)

```py
class SorcererClient:
    def __init__(self, *, connect: Callable[[], Any], dialect: "Dialect",
                 middleware: "MiddlewareAdapter | None" = None) -> None: ...

    def execute(self, sql: str, params: Any | None = None): ...  # returns cursor/driver result
    def query(self, sql: str, params: Any | None = None) -> list[tuple]: ...
    def query_row(self, sql: str, params: Any | None = None) -> tuple | None: ...

    # CRUD spells
    def insert(self, table: str, data: Mapping[str, Any]) -> int: ...
    def update(self, table: str, data: Mapping[str, Any], where: str, params: Any) -> int: ...
    def delete(self, table: str, where: str, params: Any) -> int: ...
```

### 4.3 PlaceholderEngine

```py
class PlaceholderEngine(Protocol):
    def normalize(self, sql: str, params: Any | None) -> tuple[str, Any]:
        """Accepts mixed placeholders ("%s", ":name", "%(name)s") and returns
        (driver_sql, driver_params) appropriate for the current dialect.
        Raises PlaceHolderError on mismatch (e.g., dict vs positional).
        """
```

### 4.4 Dialect protocol

```py
class Dialect(Protocol):
    name: str
    placeholder: PlaceholderEngine

    def connect(self, *, dsn: str | None, **kwargs) -> Any: ...
    def paramstyle(self) -> str: ...  # e.g., "pyformat", "format", "qmark"

    # CRUD helpers
    def compile_insert(self, table: str, data: Mapping[str, Any]) -> tuple[str, Any]: ...
    def compile_update(self, table: str, data: Mapping[str, Any], where: str, params: Any) -> tuple[str, Any]: ...
    def compile_delete(self, table: str, where: str, params: Any) -> tuple[str, Any]: ...
```

### 4.5 Middleware

```py
@dataclass
class ExecutionContext:
    sql: str
    params: Any | None
    extra: dict[str, Any] = field(default_factory=dict)

class MiddlewareAdapter:
    def before_connect(self, *, dsn: str | None = None, **_: Any) -> None: ...
    def after_connect(self, conn: Any) -> None: ...

    def before_execute(self, ctx: ExecutionContext) -> None: ...
    def after_execute(self, ctx: ExecutionContext, result: Any) -> None: ...

    def before_close(self, *, conn: Any) -> None: ...
    def after_close(self, *, conn: Any) -> None: ...
```

### 4.6 Errors (errors.py)

* `SorcererError` (base)
* `ConfigurationError`
* `ConnectionNotFound`
* `PlaceHolderError`
* `DialectError`
* `ExecutionError`

All public methods raise these, never raw driver exceptions.

## 5) Behavior Contracts

* **Named connections**: unique by name; `use(name)` swaps active connection; raises `ConnectionNotFound` if missing.
* **Param passing**: `query*`/`execute` accept either positional tuple/list or dict; mixed placeholders normalized by `PlaceholderEngine`.
* **Cursor lifecycle**: `execute` returns driver-native cursor/handle; client owns connection; middleware hooks guaranteed to run in order.
* **CRUD returns**: `insert` → lastrowid (int | 0 if unknown); `update`/`delete` → affected rows (int).

## 9) Example Usage (must work by DoD)

```py
from sorcererdb import Sorcerer
from sorcererdb.dialects.mysql import MySQLDialect
from sorcererdb.middleware.logging import LoggingMiddleware

s = Sorcerer(default="primary")
s.add_connection(
    name="primary",
    dsn="mysql://user:pass@localhost:3306/app",
    driver="pymysql",
    dialect=MySQLDialect(),
)

s.add_connection(
    name="reporting",
    dsn="mysql://report:pass@localhost:3306/analytics",
    driver="pymysql",
    dialect=MySQLDialect(),
)

s.use("primary")
client = s.client
client.insert("users", {"email": "a@b.com", "status": "active"})
rows = client.query("SELECT * FROM users WHERE status = :status", {"status": "active"})

s.use("reporting")
client.query("SELECT COUNT(*) FROM events WHERE day = %(day)s", {"day": "2025-08-22"})
```
